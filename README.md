## What I Learned

This project helped me develop a better understanding of how authentication systems work and how security controls can help protect user accounts.

While building this project, I practiced:

- Creating and organizing Python functions
- Using dictionaries to store and manage multiple user accounts
- Using loops and conditionals to control login attempts
- Hashing passwords with SHA-256 instead of storing passwords as plain text
- Comparing password hashes during authentication
- Tracking successful and failed login attempts
- Creating temporary account lockouts after repeated failed attempts
- Recording security events in a login log
- Understanding how brute-force attacks attempt to guess user credentials
- Understanding why real authentication systems use stronger password-hashing methods such as bcrypt, Argon2, or PBKDF2

This project gave me hands-on experience combining Python programming with basic cybersecurity concepts such as authentication, password protection, security logging, and brute-force attack mitigation.
